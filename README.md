# LaslesVPN Landing Page

A responsive landing page built with HTML, CSS, and Sass based on the LaslesVPN Figma design.

## Features

- Responsive design
- Semantic HTML5 structure
- Flexbox and CSS Grid layouts
- Mobile navigation menu
- Sass architecture
- Sticky navigation bar

## Built With

- HTML5
- CSS3
- Sass (SCSS)
